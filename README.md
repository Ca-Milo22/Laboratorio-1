## Aplicación integradora

`cotizador_compra.py` calcula una cotización de compra: subtotal,
descuento, base, impuesto y total. Valida que el precio, la cantidad y
los porcentajes sean números, y vuelve a preguntar si el dato es inválido.

## Cómo ejecutarla

    python cotizador_compra.py
